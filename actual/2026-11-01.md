  no console errors, no sideways scroll.

  "Suggested: 3", Put yourself in it, Plan a month. Wrong inputs: empty →
  the browser's own "Please fill out this field"; "hello there" → "That
  isn't a web address: hello"; a dead link → "The page answered 404."

  24 s, 7.8 MB, poster is the cover. Draft to Buffer: "in your Buffer

  "Write 5 videos, one per product".
- Planner: 12 posts laid out Mon/Wed/Fri from 2 Nov, each with its
  networks and "Write this video", plus "Save ticked items as Buffer
  Ideas" (not pressed, it would write to the boss's Buffer).

### Broken, and fixed today
- `/t/abc` and any wrong link answered an empty 404. Now a real page,
  `public/404.html`, served by the worker when the asset server says 404.
  First try used Wrangler's `not_found_handling: "404-page"`, which made
  the asset server answer 404 for every worker route not in
  `run_worker_first` (/me, /auth/start, /u/, /mcp) for about two minutes
  until reverted. The worker fallback does it instead. **Never set
  not_found_handling on tap.**
- Signed-out `/make/` was served as a static page (it needs Buffer).
  `run_worker_first` now lists `/make` and `/make/`, so the 302 to
  /auth/start takes effect.
- After "Write the scripts" at 390 px the page was 416 px wide (sideways
  scroll): the video card's one grid column and the scene rows were sized
  by the textareas' intrinsic width. `min-width:0` on both; main is 390.
- The read step's status line ("That isn't a web address") sat below both
  start cards, off-screen on a phone. It is under the Read button now.
- /me with ~50 old posts was 10,600 px tall, because "Bio link and counts"
  opened itself whenever there was a count. Closed by default, with the
  count in the summary ("· 1 person"); 1,258 px now. Broken Buffer
  thumbnails (grey boxes) remove themselves.
- Commits 8556909 and 6e48f4f; all deployed and checked live.
